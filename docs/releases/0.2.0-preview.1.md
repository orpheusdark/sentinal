# Sentinel 0.2.0 Preview 1

A local-first surveillance application with native desktop packages for Windows, macOS and Linux.

## Downloads

| Device | Asset | How to start |
|---|---|---|
| Windows x64 | `Sentinel-Setup-Windows.exe` | Run setup, select Install Sentinel, then Open Sentinel |
| Windows x64, portable | `Sentinel-Windows-portable.zip` | Extract the complete archive and open `Sentinel/Sentinel.exe` |
| macOS, Apple Silicon / ARM64 | `Sentinel-macOS-AppleSilicon.zip` | Extract `Sentinel.app`; distribution signing/notarization is pending |
| Linux x86-64 | `Sentinel-Linux-x86_64.tar.gz` | Extract and run `./Sentinel/Sentinel`; system GUI libraries may be required |

Python is bundled. Use Start Sentinel in the launcher to open the local dashboard. Verify downloaded files against `SHA256SUMS.txt`. `LICENSE.txt`, `THIRD_PARTY_NOTICES.md` and `Sentinel-Licenses.zip` accompany this release.

## Highlights

- Cohesive responsive dashboard with local typography, keyboard focus, labeled controls, reduced-motion support and explicit connection states.
- Working settings persistence, preview pause/refresh controls and paginated recording downloads.
- Fixed configuration overrides, fresh SQLite schema creation, session cleanup and finalized recording metadata.
- Fixed renewed-motion tails, continuous recording, retention cleanup and graceful shutdown.
- Hardened local/network access, session secrets, API keys, download paths, HTTPS verification and Telegram error handling.
- Reduced dependencies, cached frame encoding and SQL aggregate analytics.
- Native start/open/stop launcher, per-user data storage, platform build automation and comprehensive documentation.

## Preview limitations

Packages do not have distribution signing; the macOS bundle has a local ad-hoc signature and camera permission metadata. Full GUI installation, browser visual acceptance, long-running recording/cleanup, live Telegram delivery and remote TLS/mobile checks remain outstanding. This is a preview rather than a production certification.

Default access is local at `http://127.0.0.1:5000`. Network viewing requires configured authentication and a secured deployment. Phones/tablets use the responsive browser dashboard of a host; native Android/iOS camera-server apps are not included. Settings changes apply after restarting Sentinel.
