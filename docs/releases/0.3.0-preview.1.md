# Sentinel 0.3.0 Preview 1

Windows and Linux desktop applications with guided camera setup, independent camera pipelines and better recording review. Application version: `0.3.0rc1`.

## Downloads

| Platform | File | Start |
|---|---|---|
| Windows x64 | `Sentinel-Setup-Windows.exe` | Run setup → Install Sentinel → Open Sentinel |
| Windows x64 portable | `Sentinel-Windows-portable.zip` | Extract all files and open `Sentinel/Sentinel.exe` |
| Linux x86-64 | `Sentinel-Linux-x86_64.tar.gz` | Extract, then run `./Sentinel/Sentinel` |

Python is bundled. Check `SHA256SUMS.txt` and the included MIT/third-party license files. macOS/Apple builds are not part of this release.

## New features

- Camera discovery/setup wizard with snapshot preview, resolution/FPS selection and independent profiles.
- Separate camera capture, motion, recording and stream state, with up to eight configurable local devices.
- Drawn or keyboard-entered motion zones, weekday/overnight schedules and bounded recording segments.
- Optional built-in people filtering and a local COCO ONNX adapter for people/vehicles; no automatic model download.
- Linked event timeline, thumbnails, play/pause and keyboard seeking in a five-FPS in-app JPEG review preview.
- Redacted diagnostics with camera frame age, errors, FPS, processing time, database status and alert queue counters.
- Manual or opt-in startup/daily release notifications; software is never installed automatically.

## Reliability and efficiency

- Telegram delivery uses a bounded background queue, retries and cooldown instead of blocking capture.
- Cleanup protects active recordings, removes companion files and reconciles deleted video metadata.
- Motion events are independently tracked, writes are throttled and cooldown uses elapsed time.
- Fixed Linux capture backend, motion threshold direction and global recording-disable behavior.
- Reduced OpenCV thread contention; the default is one internal thread. A short synthetic 720p motion/JPEG benchmark measured about 49 FPS and 21.8 ms p95 processing time on the test machine. This is not a full-app capacity guarantee.

## Important preview limits

Windows signing support is implemented, but **no certificate was supplied**, so these packages remain unsigned. The workflow can require signing and fail when credentials are missing. Full installer/upgrade/uninstall acceptance, simultaneous physical multi-camera capacity, long-running recovery/storage tests, actual Telegram delivery, model accuracy and remote TLS deployments still need target-device validation.

Optional vehicle filtering needs a compatible user-supplied COCO ONNX model under the private `models/` directory. Built-in mode detects people only. Inference may lower that feed's FPS. Eight profiles are a configuration limit, not certified capacity. Review preview targets five FPS; original downloads retain capture FPS. Recordings have no audio.

Default access remains local at `http://127.0.0.1:5000`. Configure authentication and TLS before remote viewing. All profile/settings changes require restarting Sentinel. Existing private data is preserved by the installer.

Sentinel is useful for local DIY monitoring and customization. Keep an established recorder in service while validating it if dependable security is needed immediately.
