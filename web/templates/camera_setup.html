DEVICES / SETUP WIZARD

Camera control

Discover, preview and configure each feed independently.

WINDOWS / LINUX

1 · Find your cameras

Scans local device indices 0–7. Close other camera apps if a device is unavailable. Start with 720p at 15 FPS and check Diagnostics before adding more feeds.

Configured feeds

Up to eight cameras. Hardware capacity depends on resolution, FPS and optional inference.

2 · Preview and tune

Optional and CPU-intensive. Built-in mode detects people. Vehicle detection requires a compatible local COCO ONNX model configured on the host; no model is downloaded automatically.

Camera preview

Capture a preview to check framing. Requested and actual camera settings can differ.

Motion zones

Drag a rectangle on the preview, or add normalized coordinates below. No zones means the whole image.

3 · Set an active schedule

Schedules use the host computer's local time. With no windows, the feed records at any time. Overnight windows are supported.

Restart Sentinel after saving to apply device and pipeline changes.
