# Support

Start with [Installation](docs/INSTALLATION.md), [Troubleshooting](docs/TROUBLESHOOTING.md) and [Features and limits](docs/FEATURES.md).

If the problem remains, [open an issue](https://github.com/orpheusdark/sentinal/issues/new/choose). Include the version, operating system, architecture, reproduction steps and a short redacted log excerpt. Use the feature-request form for proposed improvements.

Security issues should follow [SECURITY.md](SECURITY.md). Do not post private video or credentials in public issues. Community support is best-effort; no response-time or production-service guarantee is provided.
